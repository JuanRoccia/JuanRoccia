## 🧠 Sobre mí

Desarrollador Full-Stack y Security Researcher basado en **Médanos, Buenos Aires, Argentina**. Co-fundador de [InmoCore](https://github.com/JuanRoccia/InmoCore) — plataforma SaaS multi-tenant para gestión inmobiliaria en el mercado argentino.

Me muevo en la intersección entre **desarrollo de producto**, **inteligencia artificial** y **ciberseguridad ofensiva/defensiva**. Construyo desde cero, rompo cosas intencionalmente, y las arreglo.

- 🏗️ Construyendo **InmoCore** — SaaS inmobiliario (React 18 + TypeScript + Express + PostgreSQL)
- 🔐 Activo en **bug bounty** (YesWeHack) y pentesting autorizado
- 🤖 Desarrollando sistemas de orquestación con agentes de IA ([workflow-harness](https://github.com/JuanRoccia/workflow-harness), [hacking-harness](https://github.com/JuanRoccia/hacking-harness))
- 📈 Algoritmic trading pipeline con LightGBM + Optuna + MLflow en homelab (Ubuntu Server)
- 🎯 En transición hacia roles remotos **SOC / Blue Team**
